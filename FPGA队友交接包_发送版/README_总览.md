# FPGA 队友交接包

本包包含两套彼此独立的模型材料：原始四分类 WDCNN，以及新的振动/电流双 WDCNN INT8 HLS 联调原型。未包含训练数据、训练代码、训练环境、虚拟环境或缓存。

## 方案目录

- `方案1_原WDCNN/`：原FP32模型、推理入口、原HLS工程/量化权重和240条软件/HLS测试向量。
- `方案2_双传感器WDCNN_INT8/`：双支路HLS顶层、fold 01原型参数、golden输入/输出、接口与融合约定。

## 输入输出差异

原方案是单通道振动、每条5120点、四分类，编号0～3的具体损伤含义仍待确认。新方案的振动为5通道、电流为2通道，各输入长度5120，分别输出健康/外圈/内圈三类分数。新方案HLS核接收已完成谱前处理、归一化和INT8量化的特征，不接收原始ADC波形。

两套方案不能混用权重、量化规则或测试输入。新方案当前模型来自交叉验证第1折，仅为HLS联调原型，不是全训练数据重新训练的最终部署模型。

## 建议流程

1. 先阅读各方案目录中的使用说明和接口约定。
2. 新方案运行 `python verify_handoff.py`，再运行其README中的主机C++测试和Vitis HLS流程。
3. 队友按实际板卡和工具版本调整器件/时钟，完成综合、RTL协同仿真、资源及时序检查后再接DMA和上板。

原方案的软件复测与新方案主机C++ golden 对照均有记录；两者都没有附本次交付环境下的HLS/上板验收结果。具体状态见各自报告。
